# IGH 智能制造平台 — 对外数据接口说明

> 文档版本：v1.0
> 编制日期：2026-11-15
> 适用系统：IGH 智能制造平台（华祥智纤九江项目）
> 文档用途：供客户方确认各阶段对外提供的数据内容与字段定义

---

## 一、通用约定

### 1.1 数据提供方式

平台在各生产阶段完成后，按阶段向外提供数据，支持两种方式：

| 方式 | 说明 | 适用场景 |
|---|---|---|
| 主动推送 | 业务发生时实时推送至客户方指定接收方 | 客户方需实时获取生产数据 |
| 查询获取 | 由客户方按条件查询 | 客户方需按批号、时间、编码等条件检索 |

接口地址、通信协议细节与账号凭证由双方在接入实施阶段确认，本文档仅约定**数据内容与字段定义**。

### 1.2 报文格式

| 项 | 约定 |
|---|---|
| 报文格式 | JSON |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`，含时区偏移，如 `2026-11-15 11:00:00 +08:00` |
| 日期格式 | `yyyy-MM-dd`，如 `2026-11-15` |
| 重量精度 | 千克（kg），保留三位小数 |
| 数量单位 | 只（锭、丝饼） |
| 空值表示 | 未采集的字段返回 `null`，不返回空字符串或 0 |

### 1.3 返回结构

**单条数据**

```json
{
  "code": 0,
  "data": { }
}
```

**列表数据**

```json
{
  "code": 0,
  "data": {
    "items": [ ],
    "total": 116
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 0 表示成功，非 0 表示失败 |
| `message` | string | 失败原因，成功时不返回 |
| `data.items` | array | 数据列表 |
| `data.total` | int | 符合条件的总条数（用于分页） |

### 1.4 分页参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page` | int | 1 | 页码，从 1 开始 |
| `page_size` | int | 20 | 每页条数，最大 200 |

### 1.5 数据唯一性与重复处理

平台对重复数据做**幂等处理**：同一业务对象重复提交或重复推送时，平台只处理一次，不会产生重复记录。客户方重试请求是安全的。

各阶段用于识别重复的业务标识如下：

| 阶段 | 业务标识 |
|---|---|
| 落筒 | 产线 + 机位 + 落筒号 + 批号 + 落筒完成时刻 |
| 栈板 | 栈板编码 |
| 丝饼 | 丝饼编码 |

### 1.6 数据关系

```
批次（批号、规格）
  └─ 落筒（产线 + 机位 + 落筒号 + 落筒时刻）
       └─ 丝饼（锭位 1..N）
            ├─ 归集到 丝车（一车承载 2~3 个落筒）
            └─ 归集到 栈板（一垛 48 锭，可跨落筒、跨丝车）
```

说明：

- 丝车与栈板之间**不直接关联**，两者均通过丝饼建立联系
- 栈板记录其装载的 48 个丝饼明细，但不记录所属丝车与落筒
- 如需由栈板反查落筒信息，可通过栈板丝饼明细中的丝饼编码逐级回溯

## 二、接口清单

| 序号 | 接口名称 | 数据对象 | 提供方式 | 触发时机 |
|---|---|---|---|---|
| 1 | 批次数据 | 批号、规格、工艺参数 | 推送 / 查询 | 批次创建或变更时 |
| 2 | 落筒数据 | 一次落筒及其锭数 | 推送 / 查询 | 落筒完成时 |
| 3 | 丝饼数据 | 单锭明细、等级、重量 | 推送 / 查询 | 落筒、外检、称重后 |
| 4 | 丝车数据 | 丝车号、承载落筒、剩余锭数 | 推送 / 查询 | 装车、取锭时 |
| 5 | 栈板数据 | 栈板编码、等级、锭数、总重 | 推送 / 查询 | 一垛堆垛完成时 |
| 6 | 栈板丝饼明细 | 栈板内 48 锭的层位 | 查询 | 随栈板数据提供 |
| 7 | 仓库库位数据 | 库位占用状态 | 推送 / 查询 | 出入库时 |
| 8 | 告警数据 | 设备告警 | 推送 / 查询 | 告警发生、确认、解除时 |
| 9 | 产量统计 | 按日、按线的产量汇总 | 查询 | 按需 |
| 10 | 称重与等级规则 | 重量区间与等级判定规则 | 查询 | 按需 |

## 三、接口字段定义

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `code` | 批号 | string | 64 | 是 | `HX-2026-001` | 业务主键，全厂唯一 |
| `name` | 批次名称 | string | 64 | 是 | `恒翔FDY 40D批次` | |
| `specification` | 规格 | string | 64 | 是 | `40D/34F` | |
| `product_type` | 产品类型 | string | 16 | 是 | `FDY` | POY / FDY / DTY |
| `order_code` | 工单号 | string | 64 | 否 | `ERP-20260101-001` | 对应客户方生产工单 |
| `spec_export` | 出口规格 | string | 64 | 否 | `40D/34F SD` | |
| `standard_china` | 执行标准（国标） | string | 64 | 否 | `GB/T 16602` | |
| `standard_export` | 执行标准（国际） | string | 64 | 否 | `ASTM D2256` | |
| `lustre` | 光泽 | string | 32 | 否 | `半消光` | 半消光 / 有光 / 全消光 |
| `twist` | 捻向 | string | 32 | 否 | `Z捻` | Z捻 / S捻 / 无捻 |
| `paper_tube_color` | 纸管颜色 | string | 32 | 否 | `白色` | |
| `default_pallet_layers` | 默认垛层数 | int | — | 是 | `6` | 栈板默认层数 |
| `default_pallet_size` | 默认每层锭数 | int | — | 是 | `8` | 栈板每层锭数 |
| `box_weight` | 箱重 | decimal | 10,3 | 否 | `734.600` | kg |
| `status` | 批次状态 | string | 16 | 是 | `active` | `active` 进行中 / `completed` 已结批 |
| `end_lot` | 是否已结批 | boolean | — | 是 | `false` | |
| `created_at` | 创建时间 | datetime | — | 是 | `2026-11-09 17:08:34 +08:00` | |

**批次重量规格（随批次数据提供）**

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `level` | 层级 | int | — | 是 | `6` | |
| `gross_weight` | 毛重 | decimal | 10,3 | 是 | `19.800` | kg |
| `net_weight` | 净重 | decimal | 10,3 | 是 | `19.200` | kg |

**批次等级范围（随批次数据提供）**

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `grade_code` | 等级 | string | 8 | 是 | `AAA` | |
| `min_weight` | 重量下限 | decimal | 10,3 | 是 | `3.150` | kg |
| `max_weight` | 重量上限 | decimal | 10,3 | 是 | `3.250` | kg |

### 3.2 落筒数据

一次落筒对应卷绕机一个机位的一次成筒作业，是丝饼数据的来源。

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `id` | 落筒编号 | int64 | — | 是 | `114` | 平台生成的落筒唯一编号 |
| `line_code` | 产线编码 | string | 16 | 是 | `L01` | |
| `line_name` | 产线名称 | string | 64 | 否 | `卷绕线01` | |
| `winder_name` | 机位名称 | string | 32 | 是 | `WDC-L01/W2/right` | 格式：设备/W机位/侧别（left 左 / right 右） |
| `doff_no` | 落筒号 | int | — | 是 | `2` | 卷绕机落筒序号；**会循环使用**（达到上限后从 1 重新开始） |
| `lot_code` | 批号 | string | 64 | 是 | `HX-2026-001` | |
| `bobbin_count` | 锭数 | int | — | 是 | `12` | 本次落筒的丝饼数量 |
| `end_time` | 落筒完成时间 | datetime | — | 是 | `2026-11-15 11:00:00 +08:00` | |
| `yarn_type` | 丝种 | string | 16 | 否 | `FDY` | POY / FDY / DTY |
| `created_at` | 数据入库时间 | datetime | — | 是 | `2026-11-15 11:00:00 +08:00` | |

**数据示例**

```json
{
  "id": 114,
  "line_code": "L01",
  "winder_name": "WDC-L01/W2/right",
  "doff_no": 2,
  "lot_code": "HX-2026-001",
  "bobbin_count": 12,
  "end_time": "2026-11-15 11:00:00 +08:00",
  "yarn_type": "FDY"
}
```

> **关于落筒号循环**：卷绕机落筒号会从上限回到 1 重新计数，因此落筒号单独不能唯一定位一次落筒。平台以「产线 + 机位 + 落筒号 + 批号 + 落筒完成时间」共同作为一次落筒的身份，可准确定位。

### 3.3 丝饼数据

单锭（丝饼）的完整明细，含外检等级、称重结果与当前位置，是质量追溯的最小单位。

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `code` | 丝饼编码 | string | 96 | 是 | `HX_2026_001-L01-W2R-261115110000-002-01` | 唯一标识，可直接扫码识别 |
| `doffing_id` | 落筒编号 | int64 | — | 是 | `114` | 所属落筒 |
| `place_in_winder` | 锭位 | int | — | 是 | `1` | 卷绕机锭位号 |
| `lot_code` | 批号 | string | 64 | 是 | `HX-2026-001` | |
| `sorting_grade` | 外检等级 | string | 8 | 否 | `AA1` | 见 5.1 等级取值 |
| `weight` | 重量 | decimal | 10,3 | 否 | `3.230` | kg |
| `weight_grade` | 称重等级 | string | 8 | 否 | `pass` | 按批次重量规则判定 |
| `final_grade` | 最终等级 | string | 8 | 否 | `AA1` | 外检等级与称重结果综合判定 |
| `defect_code` | 缺陷代码 | string | 32 | 否 | `OIL` | 多个缺陷以逗号分隔 |
| `vision_grade` | 视觉检测等级 | string | 8 | 否 | `AA` | 视觉检测系统给出 |
| `vision_defect` | 视觉检测缺陷 | string | 32 | 否 | `FRZ` | |
| `vision_confidence` | 视觉检测置信度 | decimal | 4,3 | 否 | `0.950` | 0.000 ~ 1.000 |
| `status` | 丝饼状态 | string | 16 | 是 | `completed` | `in_process` 生产中 / `sorting` 外检中 / `completed` 已完成 / `packed` 已包装 |
| `current_position` | 当前位置 | string | 32 | 是 | `warehouse` | `winder` 卷绕机 / `trolley` 丝车 / `sorting` 外检区 / `warehouse` 仓库 / `pallet` 栈板 |
| `created_at` | 创建时间 | datetime | — | 是 | `2026-11-15 11:00:00 +08:00` | |
| `completed_at` | 完成时间 | datetime | — | 否 | `null` | 全流程走完的时刻 |

**丝饼编码规则**

```
{批号}-{产线}-W{机位}{侧别}-{年月日时分秒}-{落筒号}-{锭位}

示例：HX_2026_001-L01-W2R-261115110000-002-01
      批号       产线 机位右 落筒时刻      落筒号 锭位
```

编码由业务身份直接推导，同一丝饼无论重传多少次编码不变，可直接印在标签上供扫码识别。

**数据示例**

```json
{
  "code": "HX_2026_001-L01-W2R-261115110000-002-01",
  "doffing_id": 114,
  "place_in_winder": 1,
  "lot_code": "HX-2026-001",
  "sorting_grade": "AA1",
  "weight": 3.230,
  "weight_grade": "pass",
  "final_grade": "AA1",
  "status": "completed",
  "current_position": "warehouse",
  "created_at": "2026-11-15 11:00:00 +08:00"
}
```

### 3.4 丝车数据

一车可承载 2~3 个落筒（POY 通常 2 个，FDY 通常 3 个）。平台实时给出车上剩余锭数。

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `id` | 丝车编号 | int64 | — | 是 | `9` | 平台内部编号 |
| `number` | 丝车号 | int | — | 是 | `202` | 现场车号 |
| `rfid` | RFID 标签号 | string | 64 | 否 | `E2003412012345678900002` | |
| `lot_code` | 批号 | string | 64 | 是 | `HX-2026-001` | 装载时所属批次 |
| `doffing_ids` | 承载落筒 | array | — | 是 | `[114, 115]` | 本车承载的落筒编号，数量 2~3 个 |
| `loading_time` | 装车时间 | datetime | — | 是 | `2026-11-15 11:02:00 +08:00` | |
| `status` | 丝车状态 | string | 16 | 是 | `partial` | 见下方说明 |
| `total_bobbins` | 应载锭数 | int | — | 是 | `24` | 各落筒锭数之和 |
| `remain_bobbins` | 车上现有锭数 | int | — | 是 | `4` | 实时值，随取锭变化 |

**丝车状态取值**

| 状态 | 中文 | 判定条件 |
|---|---|---|
| `full` | 满车 | 车上锭数 = 应载锭数 |
| `partial` | 部分取走 | 0 < 车上锭数 < 应载锭数 |
| `empty` | 已取空 | 车上锭数 = 0 |

> 丝车状态与剩余锭数为**实时计算值**，随丝饼被外检、打包取走而变化，与实物保持一致。

**数据示例**

```json
{
  "id": 9,
  "number": 202,
  "rfid": "E2003412012345678900002",
  "lot_code": "HX-2026-001",
  "doffing_ids": [114, 115],
  "loading_time": "2026-11-15 11:02:00 +08:00",
  "status": "partial",
  "total_bobbins": 24,
  "remain_bobbins": 4
}
```

### 3.6 栈板丝饼明细

记录每一垛装载了哪 48 个丝饼及其层位，是追溯的关键环节。

| 字段名 | 中文名称 | 类型 | 长度 / 精度 | 必填 | 示例 | 说明 |
|---|---|---|---|---|---|---|
| `pallet_code` | 栈板编码 | string | 32 | 是 | `PLT-20261115-001` | |
| `bobbin_code` | 丝饼编码 | string | 96 | 是 | `HX_2026_001-L01-W2R-261115110000-002-01` | |
| `layer` | 层号 | int | — | 是 | `1` | 该锭在第几层 |
| `position` | 位号 | int | — | 是 | `1` | 该锭在层内第几位 |

**数据示例**

```json
[
  { "pallet_code": "PLT-20261115-001", "bobbin_code": "HX_2026_001-L01-W2R-261115110000-002-01", "layer": 1, "position": 1 },
  { "pallet_code": "PLT-20261115-001", "bobbin_code": "HX_2026_001-L01-W2R-261115110000-002-02", "layer": 1, "position": 2 }
]
```

> 说明：本明细按每垛 48 条提供。栈板不直接记录所属丝车与落筒，需通过丝饼编码回溯。
